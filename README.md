# deepseekandgraphs
I asked DeepSeek 2 questions:

1. Please write a novel qiskit code to find the shortest path between 2 vertices in a weighted graph and let that code be 0.18.1 qiskit compatible.
2. Please write 0.18.1 qiskit compatible code for the same problem, but based on a Grover's search algorithm.

This repository documents respective findings.
